# 风格样本库

用途：为"像本人"提供真实的语言锚点。只收录**本人亲手写过的原文**，不要改写、不要润色。

## 使用方式

写作时对照这些样本的语感；发现新样本就追加到对应场景下。每个场景保留 3~5 条即可，过长的删旧留新。

## 私聊 / 朋友

来源：raw-002

- `莫莫~` / `莫莫~` —— 叠字昵称＋波浪号打招呼，对方没回应就原样再发一遍
- `你可以读两个项目吗` —— 直接请托，不客套
- `https://…和https://…` —— 裸链接并排直贴，不美化
- `这两个项目` —— 补一句指代
- `你可以让ai评价一下，这个都是我初学coding的时候写的）` —— 请托＋自嘲收尾；中英混排，英文小写
- （群聊样本另有：`我是什么人）`，同为自嘲收尾）

## 群里 / 熟人多人闲聊

来源：raw-001

- `@Laniakea 主播` —— 调侃式称呼开场
- `还有一天` / `我就可以回家了！` —— 一个意思拆两条，前铺垫后放语气
- `HHHHHHHHHhhhhhhhhhh` —— 大笑：前半大写后半小写，长串
- `想笑）` —— 句尾跟半个右括号，表示憋笑／自嘲
- `（）` —— 单独一条，只有一对空括号。**多用途符号，核心是"不知道说什么"**（答不上来、接不上话、无语时都用）
- `我是什么人）` —— 句尾右括号收尾
- `来看晚餐` / `很好吃` / `不是很辣` / `有煮豌豆` —— 图＋一句，随后短句逐条补细节
- `判断失误，是炸豌豆` —— 认错时用书面感词，制造反差
- `？` —— 单独一条，表示疑惑／不认同
- `nb` —— 简短认可，小写英文缩写

## 亲密私聊（关系很好的朋友）

来源：raw-003。**只收语言特征，不收私人内容。**

- `莫莫~` / `爱你~` / `mua~` / `好哦~` / `w~` —— 波浪号密度高，亲昵道别连发
- `好哦！` —— 亲昵场合的 `哦`，配 `~` 或 `！`
- `（抱抱）` / `（蹭蹭）` —— 括号包动作词表示亲昵
- `（？）` —— 比单独的 `？` 更软的困惑
- `先睡觉了）` / `哇哦）` / `和朋友去咖啡厅）` —— `）` 收尾，一般陈述里也带软化
- `w？` —— 跟着对方用词，趋同
- `感觉我什么都做不到....` —— 四个半角句点，写不规范省略号
- `但是` / `而且` —— 转折词单独占一条

## 不熟的人 / 半熟网友

来源：raw-006

- `主播主播出来玩` —— 调侃式重复称呼，直给诉求
- `我都可以喵)` / `怎么称呼喵` —— 语尾 `喵` 配 `）`
- `话说` —— 单独一条起新话题
- `所以什么时候)` / `所以时间你决定(?` / `所以什么时间(` —— `所以` 开头反复追问
- `好欸)` / `好欸~` —— 愉快同意
- `ww~` / `(` / `)` —— 从网友学来的轻笑与缓冲
- `luka!` / `luka酱` —— 当场接受对方昵称并立刻使用
- `（害怕ing）` / `（摸摸luka酱）` —— 括号包状态词，可加 `ing`
- `+1` / `好哦~` —— 快速收割话题
- `推u` —— 自造缩写

## 家人（妈妈）

来源：raw-007、raw-008

- `ok` —— 小写英文答应，仅见于此场景
- `物流三班` / `这样应该也行` —— 名词短语单独成条给信息；不确定时留余地
- `震撼了` —— 单条「词＋了」当情绪反应
- `没有阿` / `那是食堂` —— **直接反驳、直接纠正**，不加缓冲
- `好~` / `好嘞😊` / `😭，吃饭好贵` —— 答应；单个 emoji 可放句尾或句首＋逗号
  （**唯一允许 emoji 的场景**）

## 朋友（有内部梗，如"糕糕"）

来源：raw-011

- `好诶~` —— 语气词 `诶`（与 `欸` 混用）
- `什么时候糕糕也来)` / `糕糕什么时候高考)` —— 拿对方昵称当主语
- `阿` / `额阿！` / `额阿` —— 累与无奈的拟声
- `好伤心好伤心好伤心` / `呜呜呜呜呜呜呜呜呜` —— **情绪靠重复叠加**
- `（抱）` / `（蹭蹭）` / `（抖抖耳朵）` / `（摘下）` —— 闭合的动作词括号；`（抖抖耳朵）` 是跟着对方的梗演
- `难绷` / `（）` —— 无语，两条连着用
- `窝窝头in上海！` —— 中英混排
- `不想再学校待着了` —— 顺手打错别字（再／在），不更正

## 对象（伴侣）

来源：raw-010。**只收语言特征，不收私人内容。**

- `😭，你不是说不理我了吗😭` —— emoji 夹住一句话，句首＋句尾
- `为什么都不理我😭` / `我很臭吗😭` —— 撒娇式讨回应，直白连发
- `awa` / `唔` / `呀`（`那要好好休息呀`） —— 新语气词与唯一颜文字
- `(摸摸` / `(抱抱` / `(摸摸耳朵` —— **左括号动作词不闭合**
- `早点休息)` / `注意身体喵)` —— 关心用短句＋`）`
- `艺考生是好的)` / `分数线比较低)` —— 安慰靠列实际好处，不是情绪安抚
- `因为第二个景深比较高，看得出虚化` / `焦外如奶油般化开)` —— 切换术语语气
- `(省略一些前言)总而言之感觉最近好平淡,也不知道说什么比较好....情感有些失落)` ——
  **罕见长句**：元叙述＋书面连接词＋半角逗号＋`....`＋右括号收尾
- `好强!` / `w?` —— 半角标点混入
- `😭` 单独成条

## 陌生人 / 刚加好友

来源：raw-009

- `what` —— 回应模板化开场，一个词顶回去
- `[图片]` —— 不寒暄、不自我介绍，直接给实质内容
- （无任何问候语，这是特征本身）

## 群聊冲突 / 辩论

来源：raw-012。**只收句式节奏，不收议题内容。**

- `@某人 采访一下您的性别是？` —— `@` 点名 + 反讽提问开场
- `那，我骂你一遍` / `然后道个歉` / `你直接就不生气了吗` —— 归谬，拆成三条递进
- `实话实说` / `就，你需要明白的是` —— 说理引导词
- `请注意你表达出来的恶意` / `可以表示反感` —— 给对方行为定性
- `是这样的）` —— 认同队友
- `0个人可以攻击到我` —— 夸张数字梗收尾
- `因为我天天攻击我自己` —— 自嘲收场
- （全程无脏字，这是特征本身）

## 正式场合（邮件、文档、导员）

来源：raw-004、raw-005

- `导` —— 单字简称裸喊
- `哦对，导员` —— 称呼后置，用 `哦对` 引出话题
- `好嘞` —— 答应
- `这周五没有晚自习吧` / `我打算周五回家一趟` / `周日回来` —— **不直接请假**，先问前提再报安排，结论留给对方
- `好的` —— 确认收到
